MacMouse 1.0.1

- Changed the app icon and README logo background from gray to white, keeping the mouse design unchanged.
- Restored the app window’s original native background.

**Requirements:** macOS 27+, Apple Silicon. Archives: `MacMouse-v1.0.1-macOS.dmg` and `.zip`, with `SHA256SUMS.txt`.

Mice that send continuous scrolling keep the system scrolling direction. Button mappings are global. macOS actions require enabled shortcuts; desktop switching requires at least two Spaces.

Developer ID signing and notarization depend on the release credentials. Ad hoc signing alone does not provide notarization.
